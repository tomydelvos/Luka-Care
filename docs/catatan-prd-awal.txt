Target kita
Setelah setup domain selesai, hasil yang ingin kita capai adalah:

✅ http://localhost:3001
   Development

✅ https://staging.lukacare.com
   Staging

✅ https://lukacare.com
   Production Web

✅ https://www.lukacare.com
   → redirect ke lukacare.com

✅ https://api.lukacare.com
   Production API

✅ HTTPS / SSL
   Cloudflare

⬜ D1 Production
⬜ R2 Wound Image Storage
⬜ Authentication
⬜ GitHub auto deployment
Langkah berikutnya setelah domain aktif di Cloudflare adalah membuat api.lukacare.com + Worker production terlebih dahulu, lalu kita sambungkan frontend localhost:3001 ke production build secara bertahap. Saya sarankan jangan membuat D1/R2 production sebelum pemisahan environment ini selesai.
